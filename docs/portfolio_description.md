# ReadmitIQ project descriptions

## GitHub description

Patient-grouped readmission modeling and a tested FastAPI/Streamlit portfolio demo: 2.36× retrospective lift at an assumed 10% outreach capacity.

## Portfolio website description

ReadmitIQ explores how a care-management team could prioritize limited discharge follow-up.
Using 90,702 eligible historical encounters from 65,044 patients, I built a reproducible study
with patient-grouped validation, model comparison, calibration assessment and SHAP explanations.
The selected logistic model achieved held-out AP of 0.208 and ROC-AUC of 0.652. At an assumed
10% outreach capacity, it surfaced 23.54% of recorded readmissions—2.36× random targeting.
Error analysis also revealed substantially lower recall without prior inpatient use. A tested
FastAPI, Streamlit and Docker demonstration packages the original frozen model with strict
input validation and artifact integrity checks. The project demonstrates statistical judgment,
business interpretation and ML engineering; it does not claim clinical readiness, prevented
readmissions or hospital savings.

## LinkedIn Featured description

ReadmitIQ combines patient-grouped readmission modeling, explainability and business analysis
with a tested local FastAPI/Streamlit/Docker demonstration. On historical held-out data,
prioritizing the highest-risk 10% surfaced 23.54% of recorded readmissions at 2.36× lift over
random targeting. The repository documents the assumed capacity, low-history failure mode
and limits on clinical use; these are retrospective project results, not prevention outcomes.
